# X Approval Action

This is the only unavoidable external platform gate before paid third-party sale.

## Access/request route

X Ads API documentation directs developers to:

`https://ads.x.com/help`

for Ads API access requests for each developer App. For a third-party Company Service, request/coordinate review of the X Integration before commercialization and provide the English packet in `X_INTEGRATION_REVIEW_PACKET.md`.

## What must be filled before sending

- legal/company name;
- company X handle;
- developer App ID;
- current Ads API access level;
- review deployment URL;
- support contact;
- privacy-policy URL;
- screenshots/demo.
