# Sellable Beta Scope

The fastest compliant beta is intentionally narrow.

## Included
- one Client per dedicated deployment;
- conversational settings intake;
- expert settings/status table;
- creative/spec confirmation before spend;
- approval hash + separate execution key;
- bounded campaign/line-item management through supported bridge writes;
- X-native analytics reporting;
- explicit media-spend/service-fee separation;
- Client-controlled disconnect/revocation;
- first-line integration support.

## Not included in beta
- shared multi-tenant SaaS;
- shared customer database;
- automatic cross-client learning from X Materials;
- Custom Audiences;
- customer credential collection in chat;
- guaranteed autonomous optimization;
- claims of official X partnership;
- public sale before written X Integration approval.

## Launch definition

The beta becomes sellable only when:
1. X approves the reviewed integration in writing; and
2. an external/customer-like dedicated deployment passes E2E acceptance.

Everything else is post-sale optimization, not a launch blocker unless X requires it in review.
