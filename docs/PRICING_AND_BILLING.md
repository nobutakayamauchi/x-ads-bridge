# Pricing and Billing — Beta

Status: **PROPOSED, NOT FOR CHARGING UNTIL X INTEGRATION APPROVAL**

## Price

Company Service fee: **10% of finalized X Ads spend managed through the service**.

Formula:

`service_fee = finalized_x_ads_spend * 0.10`

## Billing rules

- X Ads media spend and Company Service fee are always shown as separate line items.
- Do not present the service fee as X media spend.
- Do not invoice from provisional same-day spend if a finalized value is materially different.
- If X later credits/reduces billable spend, apply the same adjustment to the service-fee base.
- No separate access premium, fixed software charge, setup fee, or hidden markup is included in the beta price.

## Example

If finalized X Ads spend is JPY 10,000:
- X Ads spend: JPY 10,000
- Company Service fee (10%): JPY 1,000
- Total economic cost to Client: JPY 11,000

Taxes, if applicable, are stated separately according to the seller's legal/tax setup.

## Change control

Any change to pricing must be checked against the then-current X Ads API Agreement and, if it affects the reviewed X Integration/commercial model, submitted to X before rollout when required.
